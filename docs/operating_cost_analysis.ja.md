## 3. 🛡️ コスト管理・ガバナンス設定手順

1. **GCP Console での予算アラート設定 (Budget Alerts)**:
   * 毎月の予想利用額に応じたアラート閾値（例: $10.00 / $50.00 / $100.00）を Billing アラートに登録。
2. **Cloud Storage (GCS) オートクリーンアップ**:
   * 動画/画像アセットバケット `antigravity-it-workout-coach-assets-4f265f3b` に 30 日間のライフサイクル削除ルールを設定。
3. **Cloud Run の最小インスタンス制御**:
   * `min_instances = 0` (常時起動なし) と設定することで、リクエストがない時間帯のインフラ代を完全 $0 に維持。
