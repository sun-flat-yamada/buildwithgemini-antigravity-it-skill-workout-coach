## 2. 📈 運用規模別コストシミュレーション

月間のアクティブユーザー数・利用ターン数に応じた 3 つの運用シナリオです。

### シナリオ A: 個人利用・ワークショップ試作用 (Small Scale)
* **月間対話ターン数**: 1,000 ターン
* **バッジ画像生成**: 20 枚
* **動画生成**: 5 本
* **想定月額コスト**: **約 70 円 ～ 180 円 ($0.45 ～ $1.20)** (GCP 無料枠によりほぼ実質無料)

### シナリオ B: チーム・部署導入規模 (Medium Scale)
* **月間対話ターン数**: 50,000 ターン
* **バッジ画像生成**: 1,000 枚
* **動画生成**: 200 本
* **想定月額コスト**: **約 2,800 円 ～ 4,800 円 ($18.50 ～ $32.00)**

### シナリオ C: 全社・エンタープライズ規模 (Large Scale)
* **月間対話ターン数**: 500,000 ターン
* **バッジ画像生成**: 10,000 枚
* **動画生成**: 2,000 本
* **想定月額コスト**: **約 42,000 円 ～ 68,000 円 ($280.00 ～ $450.00)**

## 3. 🛡️ コスト最適化・予算ガバナンスガイドライン

1. **GCP 予算アラート (Budget Alerts) の設定**:
   * GCP Console にて $10.00 / $50.00 / $100.00 の閾値でメールアラートを設定推奨。
2. **GCS アセット自動削除ルールの設定**:
   * 一時的な動画ティーザーやバッジ画像がストレージを圧迫しないよう、`antigravity-it-workout-coach-assets-4f265f3b` バケットに **30 日自動削除ライフサイクルルール** を適用。
3. **Cloud Run インスタンス最適化**:
   * `min_instances = 0` (アイドル時課金ゼロ) および `concurrency = 80` を設定し、リソース利用効率を最大化。
